# stackframe

Stack and reshape frame text streams with deterministic transforms.

**Site:** https://theworker02.github.io/stackframe/

## Install / run

```bash
git clone https://github.com/theworker02/stackframe.git
cd stackframe
node src/cli.js
node --test
```
